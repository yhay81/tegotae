# Decisions

## 2026-07-30 — 30-day public pilot

- Status: advance to a reversible public pilot; investment remains hold.
- Evidence: Ninja Analytics still displays an ad banner and retains logs for only four months, while current free alternatives already offer privacy-first or ad-free analytics.
- Decision: test a narrower one-screen Japanese product that stores aggregates only and requires no account.
- Contradicting evidence: Cloudflare Web Analytics is free and privacy-first; Access Analytics Lab is free, ad-free while active, and real-time. Simple feature parity is not a durable advantage.
- Next review: 2026-08-29, using real installation, multi-day data, dashboard reuse, and explicit replacement intent.
